## What was built

- **Pure domain (`celestina-shell`).**
  - `weather.rs` is a copy by salvage of `celestina-shell-core/src/weather.rs`
    (request URL, bounded reply read, retry step, freshness rule, with their
    tests); its head comment records the source path and commit. `Location`
    lives in `settings.rs` with its coordinates in whole micro-degrees so
    `Settings` stays `Eq`.
  - `settings.rs` gained the optional `weather` object (`latitude`, `longitude`,
    `label`). It is lenient: a wrong type, an out-of-range coordinate or a label
    over 64 characters reads as no location, and the key is never written when
    unset. `schema_version` is unchanged.
  - `glance.rs` is new and small: the `Load` thresholds (80 elevated, 90
    critical) and today's date (year, month, day, weekday) from unix seconds and
    an offset, reusing `calendar.rs`.
- **Providers (`celestina/src/providers/`).**
  - `sysmon.rs`: a worker behind a `ProcSource` trait (the real one reads
    `/proc/stat`, `/proc/meminfo` and `/sys/class/hwmon`, bounded; tests use a
    fixture source). It samples every 2 s, publishes only on change, keeps a
    60-sample `VecDeque` history per series and withdraws the reading on error.
    The parsing is `hematita-core::{cpu, memory, sensors}`.
  - `weather.rs`: a worker behind a `Fetch` trait, with the `curl` fetcher and
    the decision loop of the core. It takes the location through a handle the
    settings update. With no location it makes no request and its reading is
    withdrawn.
- **Wiring.** `glance.rs` (the app's handle, like `EnergyHandle`) starts the
  sysmon worker only while `sysmon` is placed in a bar zone and the weather
  worker only with a valid location and a placed `weather` or `clock` piece,
  idempotently on every follow of `shell.json`, and stops both on exit. The
  reaper that joins finished workers moved from `energy/mod.rs` to
  `providers/worker.rs` so the three duty groups share it.
- **Pieces and pages.** Three pieces after the CEL-2-A table: `sysmon`
  (`CPU 23% · RAM 41%`, coloured by `Load`), `weather` (whole degrees and a
  condition glyph, absent without a fresh reading) and `clock` (the short date).
  None is in the default zones. The Island gained the **Sistema** page (CPU and
  memory, the hottest CPU temperature when hwmon has one, a sparkline per
  series, a row that opens the monitor) and the **Reloj** page (the seconds
  clock, a Monday-first month grid of always six rows, Previous / Today / Next
  buttons, and the weather reading when present). The displayed month is Island
  page state and resets when the page closes. `island open` accepts `sysmon` and
  `clock`. The Spanish copy (weekday and month names, condition words per
  Open-Meteo code, labels, the launcher words `/reloj` and `/sistema`) is in
  `copy.rs`.
- **Cadence.** The sysmon worker publishes every 2 s, but the bar shows it on a
  10 s clock (`island/cadence.rs`), so the bar's rest stays at a handful of
  frames; an open page uses the page clock's one-second tick.
- **Smoke.** `scripts/smoke.sh` gained two runs (below).

## Decisions as they ended, and deviations from the design

- **D1 — the monitor row opens Hematita,** `org.celestina.Hematita.desktop`,
  not Mission Center as the design says: Hematita is the suite's resource monitor.
- **D2 — no warning role.** The theme has no warning colour: `Load::Elevated`
  uses the Accent role and `Load::Critical` the Danger role.
- **D3 — no moon icon.** No moon icon exists, so a clear
  night shows the temperature as text only, without a glyph.
- **D4 — five tabs are cramped.** With Activity, Notifications, Tray, Sistema
  and Reloj the tab row is about 71 px per tab and "Notificaciones" may
  overflow. Not changed in this unit; queued as `VAL-CEL2-GLANCE-TABS`.
- **D5 — the reaper moved** from `energy/mod.rs` to `providers/worker.rs`
  (listed above), a behaviour-preserving move.
- **D6 — Reloj grid is always six rows,** so the page does not change height
  from one month to the next.
- **D7 — `hematita-core` use is narrower than the design.** The system monitor
  uses `cpu`, `memory` and `sensors`; it does **not** use
  `hematita-core::history`: the history is a `VecDeque` of 60 samples in the
  worker. The architecture standard lists exactly those three modules (the
  design's §5 said four).
- **D8 — curl hardening.** The fetcher runs `curl --disable --proto =https
  --max-filesize` besides `--fail --silent --max-time`: no user `.curlrc`, https
  only, bounded body.
- **D9 — curl inherits the environment.** It honours proxy variables and sends
  its default user agent; the shell does not scrub either. The request still
  carries only rounded coordinates and the three fields.
- **D10 — a coordinate edit skips the failure pause.** A new location triggers
  its request at once, so one edit costs one request; a failing endpoint is
  still retried only after the five-minute wait.
- **D11 — an oversize label is hostile.** A weather label over 64 characters
  makes the whole location `None` instead of being truncated.
- **D12 — the Hematita dependency is registered.** `hematita-core` is in
  `celestina/Cargo.toml` with its justification, in `docs/projects.toml`
  `production_inputs` of `celestina`, and in
  `docs/standards/architecture.md` as a narrow consumer.
- **D13 — the network rule is an ADR,** 0016, which records the design's three
  decisions (weather as the only network and manual, three pieces and one page,
  the shared parsers).

## Limits

Nothing was checked in a real session. Not proven:

- **A real fetch.** No test or smoke reached Open-Meteo; the smoke's `curl_calls`
  counts calls of its fake `curl`. The live request, TLS, a real reply and a real proxy
  environment are the author's row `VAL-CEL2-WEATHER`.
- **Real `/proc` and hwmon on the author's machine:** the tests use a fixture
  source. Whether the numbers agree with a monitor, whether the right hwmon
  sensor is the hottest CPU one and the colour change under load are
  `VAL-CEL2-SYSMON`.
- **The calendar and the date on the real wall clock,** month navigation, the
  today highlight and the day change at midnight: `VAL-CEL2-CALENDAR`.
- **The five-tab width** at the real scale and the 4K output:
  `VAL-CEL2-GLANCE-TABS`.
- **Appearance:** glyph shapes, the sparkline, alignment of the calendar grid
  and contrast of the Load colours against the Haze at scale 1.5.
- **No outbound connection with no location,** beyond the smoke's `curl` child
  count and the network guard test; a packet capture was not taken.
- **Production entries.** `build-production.sh`, `verify-production.sh` and
  `deploy-production.sh` were not run in the worktree: AGENTS.md has the landing
  run them on the tree it commits.
- **Keyboard and assistive technology** for the two new pages: the bar takes no
  keyboard yet (ADR 0007); the pages are reachable through `island open`.

  unplaced piece starts no worker.

## Review

Two independent read-only reviews at high reasoning, each by a model other
than the one that wrote the code: Opus 5.5 reviewed the Sonnet 5.5 parts
(core crate, sysmon provider, pieces, pages, smoke) and Sonnet 5.5 reviewed the
Opus 5.5 parts (weather provider, glance handle, cadence, wiring). Neither
found a path where a request leaves the machine without a valid manual
location.

Fixed after review (one pass, tests added for each):

- Workers now follow the bar duty as well as placement; a bar that is off
  samples nothing and asks for no weather.
- A weather worker found gone is dropped and respawned by the next apply; a
  full queue keeps the slot and resends.
- Freshness and pacing use a monotonic clock; wall time only labels the
  reading. Requests are at least 60 s apart whatever caused them, and a moved
  location withdraws the old reading before the blocking fetch.
- Behavioural tests for the curl fetcher (success, failure, oversize, hang
  killed at the hard limit and reaped, missing program, shutdown mid-request)
  with local script stand-ins, and for the app glue (`glance::admit`, removal
  of the location).
- Five tabs overflowed: the Notifications tab shows `Notific.`; a test
  measures every label against its pill with the real font.
- The System and Clock pages say what is missing (a placed piece, the bar)
  instead of staying silent; design §4 was amended: an open page alone does
  not start a worker.
- A missing or undefined weather code is shown as unknown, never clear sky.
- One label rule (strip controls, trim, truncate to 64 scalar values) and a
  `Debug` for `Location` that never prints coordinates.
- `Today::from_unix` returns `None` outside years 1 to 9999.

Not fixed, by decision: the cached UTC offset (pre-existing) makes the date
off by an hour after a DST change until restart; the curl child inherits the
person's proxy environment and sends curl's default user agent; the monitor
row is shown even if Hematita is not installed; "Anterior"/"Siguiente" have no
accessible name because the toolkit has no such channel; `taken_unix` changes
on each refresh and redraws the bar every 15 min.
