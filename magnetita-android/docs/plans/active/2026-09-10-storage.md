## Hypothesis

The folder the person picks once in the system's tree picker is the root
the desktop browses: the storage access framework's persisted grant, the
documents contract for listings, entries, ranges and changes, and nothing
the platform does not give. The wire's paths map onto document ids by
appending, so no path is ever built from strings the desktop chose.

## Tangible outcome

The device screen's "Archivos" row; Siderita browsing that folder through
the daemon's mount.
