# Magnetita Android evidence

Dated records in this directory contain agent-executable evidence for
Magnetita Android implementation units. Author-only phone checks remain in
`magnetita-android/VALIDATION.md` and, for the first pairing, in
Magnetita's `VALIDATION.md`.

Use `YYYY-MM-DD-short-topic.md` and the suite
[evidence template](../../../docs/templates/evidence.md).
