- **Date:** 2026-11-27
- **Scope:** `RS-L10N-A`: `celestina-rs/crates/celestina-core/src/desktop_entry.rs`, `scripts/qmllint-baseline.tsv` (re-measured, below), the one-unit plan `RS-L10N`, the roadmap's checkpoint, the plans index and the status
- **Environment:** worktree `celestina-rs-RS-L10N-A` from `main` at `756e9e6e`; a private cargo target directory
- **Artifact:** not applicable in the session (the landing rebuilds and verifies every app that links the crate)
- **Why:** the shell's launcher search (`CEL-I-015`, [design](../../../docs/superpowers/specs/2026-11-26-celestina-launcher-design.md) §5.6, [plan](../../../docs/superpowers/plans/2026-11-26-celestina-cel-i-015-plan.md) Task 1) needs the localized `Name`, `GenericName` and `Keywords` the reader dropped. The author chose this one-unit plan on 2026-11-27.

## Change

- `DesktopEntry` gains `name_l10n`, `generic_name_l10n`, `comment_l10n` and `keywords_l10n`, each a list of (locale tag as written, value), at most `MAX_LOCALIZED_PER_KEY` (64) per key, unescaped under `read` as the unlocalized values are.
- `Locale` parses `lang_COUNTRY.encoding@modifier`: it drops the encoding, and `C`, `POSIX`, an empty value and a value with no language give no locale. `from_vars` and `from_env` take the first non-empty of `LC_ALL`, `LC_MESSAGES` and `LANG`.
- `localized_name`, `localized_generic_name` and `localized_keywords` return the first match in the specification's order: `lang_COUNTRY@MODIFIER`, `lang_COUNTRY`, `lang@MODIFIER`, `lang`.
- Every existing field and function keeps its behaviour; no consumer changes.
