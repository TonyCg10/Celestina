## Procedure

TDD per module: tests written first with `todo!()` bodies, run to confirm
`not yet implemented` failures, then the bodies implemented and run again.

```sh
cd celestina-rs && cargo test -p hematita-core rate
cd celestina-rs && cargo test -p hematita-core disk
cd celestina-rs && cargo test -p hematita-core network
cd celestina-rs && cargo test -p hematita-core gpu
cd celestina-rs && cargo test -p hematita-core history
cd celestina-rs && cargo test -p hematita-core && cargo fmt --all --check && cargo clippy --locked -p hematita-core --all-targets -- -D warnings
```

Then the fixtures were captured and the capture tests added:

```sh
cat /proc/diskstats > celestina-rs/crates/hematita-core/tests/fixtures/proc-diskstats.txt
cat /proc/net/dev > celestina-rs/crates/hematita-core/tests/fixtures/proc-net-dev.txt
grep -cE ' (sd[a-z]+|nvme[0-9]+n[0-9]+|vd[a-z]+|mmcblk[0-9]+) ' celestina-rs/crates/hematita-core/tests/fixtures/proc-diskstats.txt
grep -c ':' celestina-rs/crates/hematita-core/tests/fixtures/proc-net-dev.txt
```

which printed `4` whole devices (`nvme0n1`, `nvme1n1`, `sda`, `sdb`) and `3`
lines with a colon in `/proc/net/dev`, one of them `lo`, giving `DISKS = 4`
and `INTERFACES = 2` for `tests/captures.rs`. Final gate:

```sh
cd celestina-rs && cargo test -p hematita-core && cargo fmt --all --check && cargo clippy --locked -p hematita-core --all-targets -- -D warnings
```
