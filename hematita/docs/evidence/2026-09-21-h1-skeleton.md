## Procedure

Builds are expensive on this machine; the controller ruled out
`verify-production.sh` for this batch (a second heavy compile for a stub) in
favour of one release build followed by the fast gates below:

```sh
(cd celestina-rs && cargo test -p hematita-core && cargo fmt --all --check && cargo clippy --locked -p hematita-core --all-targets -- -D warnings)
hematita/scripts/build-production.sh
(cd hematita && cargo fmt --all --check && cargo clippy --release --all-targets --locked -- -D warnings && cargo test --release --all-targets --locked)
hematita/scripts/smoke.sh
scripts/qmllint-cxxqt.sh hematita
bash scripts/check-architecture-contract.sh
bash scripts/check-documentation-contract.sh
python3 scripts/check-language-contract.py
```
