## What the review found

1. A cancel inside the last (or only) item reported `partial`, not
   `cancelled`: `stopped` turned any failure that had removed something into
   a partial and dropped the cancellation, and the loop only checked the
   token before the next item. The first step of `VAL-S2` is exactly this
   case.
2. The confirmation was bound only to the selection's count, so swapping one
   selected entry for another while the dialog was open acted on entries the
   person had not been asked about.
3. Minors: the refusal named the asked count, not the live one;
   `Session::graft` extended `unreadable` without first aligning it to the
   graft offset; `analysis_workers.rs` wrote the session's epochs, handles
   and graft list directly. Two minors stay documented, as `S2-B` recorded:
   only a `NotFound` root error prunes a graft, and duplicates inside a
   grafted folder wait for a rescan.

## What changed

1. **Cancel inside an item.** `Step::Partial { gone, cancelled }` keeps
   whether the stop was `RemoveError::Cancelled`. `run` records the item as
   partial with its bytes, then marks the action cancelled and stops, so the
   outcome is `cancelled` and the hub still grafts that folder. `run`
   returns its `ActionReport` and takes a progress closure, so it is tested
   without a Qt thread.
2. **Selection revision.** `Session` keeps the selection private with a
   `selection_revision` moved by every change of the selected set (toggle,
   select all but one, clear, reset, load, prune, graft). The hub publishes it
   as `selectionRevision` in the same pass as `selectedCount`, before
   `revision`. The Storage page carries it in the dialog's payload (and the
   single-entry trash passes the current one); `trashSelected` and
   `deleteSelected` refuse with `refused` when it moved.
3. **Refusal count.** The refusal's total is the live outermost count.
4. **Graft alignment.** `unreadable.resize(offset, 0)` before `extend`.
5. **Session methods.** `set_confirm`, `confirm_done`, `next_action_epoch`,
   `set_action`, `action_done`, `start_graft`, `take_graft`,
   `clear_selection`; the workers no longer write session fields directly.
6. **VAL-S2** gains the same-count swap step and a cancel inside one folder.
