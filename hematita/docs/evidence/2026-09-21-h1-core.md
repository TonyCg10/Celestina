## Procedure

TDD per module: tests written first with `todo!()` bodies, run to confirm
`not yet implemented` failures, then the bodies implemented and run again.

```sh
cd celestina-rs && cargo test -p hematita-core cpu
cd celestina-rs && cargo test -p hematita-core memory
cd celestina-rs && cargo test -p hematita-core history
cd celestina-rs && cargo test -p hematita-core && cargo fmt --all --check && cargo clippy --locked -p hematita-core --all-targets -- -D warnings
```

Then the fixtures were captured and the capture tests added:

```sh
mkdir -p celestina-rs/crates/hematita-core/tests/fixtures
cat /proc/stat > celestina-rs/crates/hematita-core/tests/fixtures/proc-stat.txt
cat /proc/meminfo > celestina-rs/crates/hematita-core/tests/fixtures/proc-meminfo.txt
cat /proc/cpuinfo > celestina-rs/crates/hematita-core/tests/fixtures/proc-cpuinfo.txt
grep -c '^cpu[0-9]' celestina-rs/crates/hematita-core/tests/fixtures/proc-stat.txt
grep -m1 'MemTotal' celestina-rs/crates/hematita-core/tests/fixtures/proc-meminfo.txt
```

which printed `8` cores and `MemTotal:       65403392 kB`, giving `CORES = 8`
and `TOTAL_KIB = 65_403_392` for `tests/captures.rs`. Final gate:

```sh
cd celestina-rs && cargo test -p hematita-core && cargo fmt --all --check && cargo clippy --locked -p hematita-core --all-targets -- -D warnings
```
