# Fluorita implementation plans

Plans in this directory promote one settled roadmap checkpoint into bounded
implementation units and a persistent commit ledger. Active and archived plans
live in their respective subdirectories. Unit inventories live permanently
under [`../inventories/<plan-slug>/<unit>.numstat.tsv`](../inventories/).
Archiving moves only the plan with its basename, `Plan ID`, checkpoint, units
and links intact; a separate archive commit gets an administrative unit and new
inventory.
