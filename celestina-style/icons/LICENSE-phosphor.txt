Applies to the filled content-icon geometry vendored in
CelestinaIconShapes.qml, which is generated from the Phosphor Icons fill set
(https://github.com/phosphor-icons/core, tag v2.0.8) by
scripts/sync-phosphor-shapes.sh. No Phosphor SVG file is shipped: the singleton
carries only the extracted path data, which is a derivative of that source and
travels under the same notice.

The stroke UI glyphs in this directory are Lucide and carry their own notice in
LICENSE-lucide.txt.
