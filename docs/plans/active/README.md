# Active suite plans

implementation checkpoint. The active suite plan is
[PRD-1 desktop entry registration](2026-08-05-desktop-entry-registration.md);
LNG-1 closed on 2026-08-05 and moved to [`../archive/`](../archive/).

Each unit stores its inventory under
[`../../inventories/<plan-slug>/<unit>.numstat.tsv`](../../inventories/). The
inventory remains there when only the completed plan moves to `../archive/`.
