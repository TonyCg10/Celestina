# Suite discussions

A material unresolved question lives here until decided. Plans receive work
only after a verdict.

Lifecycle:

1. `open`: proposal, strongest counter-case, alternatives, and falsifiers are
   still being examined.
2. `concluded`: a verdict exists but is not yet applied to canonical sources.
3. `applied`: decision, roadmap, and contracts were updated as instructed.

Start from the [discussion template](../templates/discussion.md). Preserve
rejected alternatives and superseded reasoning; never present an open
discussion as current policy. Every local index links each record exactly once
and keeps status current. A concluded record links the canonical home targeted
by its verdict; an applied record also links the updated decision, contract, or
roadmap.

There are currently no active suite-level discussions in this foundation.
Project questions stay in the owning project's `docs/discussions/`.
