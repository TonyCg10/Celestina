# History

Este directorio preserva documentación retirada que todavía explica el origen
de una decisión o contrato. No es fuente vigente de reglas, estado o backlog.

Al migrar material:

- conserva contenido útil y fecha;
- añade un encabezado que nombre el documento canónico sucesor;
- mantiene enlaces entrantes mediante un pointer breve cuando sean conocidos;
- no corrige retrospectivamente afirmaciones antiguas salvo una nota fechada.

No se borra historia para hacer que el estado actual parezca más limpio.
