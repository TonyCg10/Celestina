# Evidence records

Evidence records observed facts, not intent. A dated record identifies scope,
revision/worktree, environment, command or procedure, result, and limitations.

- Commands include exit status; empty summaries are not evidence.
- Do not claim a higher layer than observed: build is not interaction;
  offscreen is not a real compositor; mocks are not hardware.
- When a check did not run, record why.
- Append a dated correction instead of rewriting a historical result.

Short unit evidence may live in its ledger. Create a record here when the
procedure or result needs durable detail or reuse.
