# Orphan discussion

- **Opened:** 2026-08-03
- **Status:** open
- **Question:** Is an unindexed record visible?

## Context

The record exists.

## Strongest case

Every record should be indexed.

## Counter-case

The file can be found by scanning.

## Alternatives

Keep an explicit finite index.

## Falsifiers and evidence needed

An index-free tree would need equal deterministic discovery.

## Conclusion

Keep the index.
