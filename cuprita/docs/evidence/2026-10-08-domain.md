## Limits

- The QML page tests run under `qmltestrunner`, where Rust types do not
  exist: the pages take their controller and models as properties and the
  tests hand them QML stand-ins scripted like the crate's fakes
  (`cuprita/tests/qml/fakes`). The Rust controllers over the real fakes are
  exercised by the smoke and the manual run above, not by those tests.
- cxx-qt-build takes one QML module's bridge files from one directory, so the
  list-model bridges live in `src/controller/` beside the controllers (and
  `activation.rs` moved there); `src/models.rs` keeps the shared reconcile
  recipe.
- No agent request is raised yet (the BlueZ agent is CUP-1-D); the Wi-Fi
  password and pairing dialogs are not built.

## Review fixes

- `reconcile` drops a repeated key (the first row wins) and trims rows past
  the snapshot's length; a key found further down is now a real
  `beginMoveRows`/`endMoveRows` move, so its delegate survives. Unit tests: a
  duplicate key ([x, x, y] then [x] → one row), a key moving from index 2 to 0
  reported as one move.
- The page tests use QML stand-ins (`cuprita/tests/qml/fakes`, mirroring
  `fake.rs` field by field); the smoke now covers the real controller → hub →
  model wiring: with `CUPRITA_FAKE=1` and `CUPRITA_SMOKE_REPORT=1` the window
  prints its models' rows and the smoke fails unless it reads
  `networks=4 devices=2 endpoints=3 streams=2` with a default sink and source.
- The stand-ins' setDefault/setMuted cover sources too (new test: the input
  mute toggles the microphone); the stream icon matches `fake.rs`.
- Comments: the worker thread is detached and never joined; `deliver` runs
  under the hub's mutex and must only queue.
